# Digital Banking Platform

Spring Boot ve Spring Cloud ile geliştirilmiş mikroservis mimarili dijital bankacılık platformu simülasyonu.

## Mimari
(Buraya ileride mimari diyagramı ve servis listesi eklenecek)

## Servisler
- eureka-server — Service Discovery
- api-gateway — Tek giriş noktası
- auth-service — Kimlik doğrulama
- customer-service — Müşteri yönetimi
- account-service — Hesap yönetimi
- transaction-service — Para transferi
- notification-service — Bildirimler
